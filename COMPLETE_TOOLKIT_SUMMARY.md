## 🎯 What Each Tool Does

### 1. Basic Diversity Analysis
**File:** `tcr_diversity_analysis.py`

**Calculates:**
- Shannon entropy
- Simpson index
- Clonality
- Clone richness

**Compares:** CMV+ vs CMV- with statistical tests

**Controls for:** Age, sex, ancestry confounders

---

### 2. V/D/J Gene Usage
**File:** `tcr_vdj_analysis.py`

**Analyzes:**
- V gene segment usage
- J gene segment usage
- D gene segment usage
- V-J pairing patterns

**Identifies:** Disease-associated gene preferences

---

### 3. GIANA Clustering ⭐ NEW!
**File:** `tcr_giana_analysis.py`

**Discovers:**
- **Public TCRs** - Sequences shared across individuals
- **CDR3 Motifs** - Common amino acid patterns (3-mers)
- **Sequence Clusters** - Similar CDR3s (1 AA difference)
- **CMV Associations** - Disease-specific features

**Based on:** GLIPH (Glanville 2017), TCRdist methods

**Key Features:**
- Hamming & Levenshtein distance calculations
- Motif enrichment analysis
- Public TCR detection (≥2 individuals)
- CMV-enrichment scoring

### Custom Analysis Example:

```python
#!/usr/bin/env python3
from tcr_utils import *

# Load data
df = load_tcr_data("data/part_table_bfi-0000234.tsv")

# Calculate diversity
summary = summarize_repertoire(df)
print(f"Shannon: {summary['shannon']:.3f}")
print(f"Clonality: {summary['clonality']:.3f}")

# Extract motifs
for cdr3 in df['cdr3_aa'].head():
    motifs = extract_cdr3_motifs(cdr3, k=3)
    print(f"{cdr3}: {motifs}")
```
